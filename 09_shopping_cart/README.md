# Shopping Cart UI

## Description

A functional, responsive shopping cart interface built with HTML, CSS, and Vanilla JavaScript.

## Features

- Dynamic order summary calculation (Subtotal, Tax, Grand Total)
- Interactive quantity adjustment (+ / - buttons)
- Remove item functionality with smooth CSS fade-out
- Responsive layout (side-by-side on desktop, stacked on mobile)
- Event delegation used in JavaScript for efficient event handling

## Technologies

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6, DOM Manipulation)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Using JavaScript Event Delegation (`target.closest()`) to handle clicks efficiently on dynamic elements.
- Storing base values in HTML `data-` attributes (`data-price`) and retrieving them via JS to perform math safely.
- Calculating and formatting currency output in JavaScript.
