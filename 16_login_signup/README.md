# Login & Sign Up UI

## Description

A modern, interactive authentication interface featuring toggleable Login and Sign Up forms within a single card layout. It includes password visibility toggles and real-time JavaScript validation.

## Features

- Sleek unified card layout swapping between Login and Signup via JS
- Password visibility toggle (Eye icon)
- Form inputs styled with inline FontAwesome icons
- Comprehensive custom JavaScript validation preventing submission if rules are not met
- Custom error state styling (`.error-input`)

## Technologies

- HTML5
- CSS3 (Animations, Flexbox)
- JavaScript (DOM Manipulation, Form Validation)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Managing multiple forms within a single view using CSS classes and JS event listeners for toggling.
- Implementing a password visibility toggle by changing the `type` attribute of an input field from `password` to `text`.
- Writing robust custom form validation logic in JavaScript instead of relying solely on HTML5 attributes, allowing for custom error messages below each field.
