# Restaurant Menu

## Description

A luxurious and elegant landing page for a fine dining restaurant. It includes a beautiful hero section, an about section, and a categorized menu display.

## Features

- Full-screen hero section with background image and dark overlay
- Premium dark theme with gold (`#d4af37`) typography and accents
- Typography pair: 'Playfair Display' for headings and 'Lato' for body text
- Responsive flexbox and grid layouts
- Categorized menu grid with elegant item pricing lines
- Smooth scrolling navigation

## Technologies

- HTML5
- CSS3 (Flexbox, CSS Grid)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing an elegant dark UI for the food & beverage industry.
- Using CSS Grid for displaying a restaurant menu seamlessly on different screen sizes.
- Implementing dotted borders and flex-between alignments to create classic menu pricing structures.
