# Contact Page

## Description

A clean and professional contact page featuring a split layout. One side contains a message form, and the other side displays company contact information, social links, and a map placeholder.

## Features

- Flexbox split layout
- Form with floating-style focus states
- Contact information section with FontAwesome icons
- Interactive social media buttons
- Hoverable map placeholder
- Fully responsive (stacks vertically on mobile)

## Technologies

- HTML5
- CSS3 (Flexbox, Hover States, Shadows)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing a unified card containing two distinct visual sections (solid color side vs. white form side).
- Using flexbox ordering (`order: 2`) in media queries to ensure the form appears above the contact info on mobile devices.
- Implementing an image overlay effect on hover for the map placeholder.
