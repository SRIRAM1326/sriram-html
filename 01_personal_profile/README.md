# Personal Profile Page

## Description

A clean, modern, and fully responsive personal profile webpage. It serves as a digital business card, featuring a sleek glassmorphism design, dark mode aesthetic, and interactive micro-animations.

## Features

- Modern dark theme with ambient background gradients
- Glassmorphism effects using backdrop-filter
- Profile avatar with hover zoom effects
- Contact information and location details
- Interactive skills tags
- Social media links with hover animations
- Fully responsive layout for all devices

## Technologies

- HTML5
- CSS3 (Flexbox, CSS Variables, Animations)

## How to Run

Open `index.html` in a web browser. No local server is strictly required, though it is recommended for best performance.

## What I Learned

- Implementing glassmorphism using CSS `backdrop-filter` and transparent backgrounds.
- Using CSS custom properties (variables) for consistent theming.
- Structuring semantic HTML for an accessible profile page.
- Adding smooth micro-animations on hover states to improve user engagement.
- Designing responsive cards suitable for mobile devices.
