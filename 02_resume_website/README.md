# Resume Website

## Description

A professional, modern, and fully responsive online resume website. Designed to showcase a developer's experience, education, skills, and projects in an elegant layout.

## Features

- Clean two-column layout (sidebar for profile/contact, main for details)
- Professional typography with 'Outfit' and 'Roboto' fonts
- Responsive design that stacks beautifully on mobile devices
- Sectioned content for Experience, Education, Projects, and Certifications
- Download Resume button
- FontAwesome icons for visual enhancement

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Structuring a complex page using CSS Flexbox for the main wrapper and CSS Grid for internal elements like projects.
- Creating a clear visual hierarchy for resume timelines.
- Handling responsive design to shift from a side-by-side layout to a stacked layout on smaller screens.
