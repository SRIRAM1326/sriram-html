# 20 HTML, CSS & JavaScript Mini Projects 🚀

Welcome to the **HTML Mini Projects** repository! This collection features 20 completely independent, beginner-friendly web projects built entirely from scratch using pure HTML5, CSS3, and Vanilla JavaScript. 

No frontend frameworks (like React, Vue, or Angular) or CSS libraries (like Bootstrap or Tailwind) were used. This makes it an excellent resource for anyone looking to master the fundamentals of modern web development, UI/UX design patterns, and DOM manipulation.

## 🌟 Key Features Across Projects

- **Modern UI/UX Design**: Uses principles like Glassmorphism, CSS Grid, Flexbox, hover animations, and dark mode.
- **Fully Responsive**: All projects are designed to look great on both desktop and mobile screens.
- **Zero Dependencies**: Every project is self-contained. There is no `npm install` or build step required.
- **Vanilla JavaScript**: Projects that require logic (like the To-Do app, Pomodoro timer, or Shopping Cart) use standard ES6+ JavaScript.

## 🛠️ How to Run

Because these projects are built with standard web technologies, there is no setup required!

1. Clone or download this repository.
2. Navigate into any project folder (e.g., `cd 01_personal_profile`).
3. Double-click the `index.html` file to open it directly in your default web browser.

*Alternatively, you can open the entire folder in an editor like VS Code and use the "Live Server" extension for a better development experience.*
