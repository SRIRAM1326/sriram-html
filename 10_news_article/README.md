# News Article Page

## Description

A clean, highly readable modern news article template utilizing standard journalistic design patterns. It focuses on typography and semantic HTML structure.

## Features

- Semantic HTML (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`, `<figure>`, `<figcaption>`)
- Typography pairing: 'Open Sans' for UI elements and 'Merriweather' for reading text
- Author metadata block with share buttons
- Pull quotes styling
- Sidebar for related articles

## Technologies

- HTML5
- CSS3

## How to Run

Open `index.html` in a web browser.

## What I Learned

- The importance of using correct semantic HTML tags for SEO and accessibility, such as separating the article body from the site-wide main block.
- Styling traditional pull quotes utilizing borders and italic serif fonts.
- Managing readability by restricting the maximum width of the reading area (`max-width: 800px`).
