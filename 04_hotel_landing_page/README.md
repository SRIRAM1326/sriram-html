# Hotel Landing Page

## Description

A luxurious hotel landing page designed for an upscale resort. It features a sticky navigation bar, a striking hero section, room showcases, and guest reviews.

## Features

- Elegant color palette (deep ocean blue, warm gold, white)
- Serif ('Cormorant Garamond') and Sans-serif ('Montserrat') typography pairing
- Room cards with imagery, descriptions, and booking buttons
- Icon-based amenities grid
- Responsive layout for desktop and mobile devices

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing overlapping layout elements using Box-Shadow to create an offset border effect for images.
- Using background-blend-mode and linear gradients over images for readable hero text.
- Creating card components that transition beautifully on hover.
