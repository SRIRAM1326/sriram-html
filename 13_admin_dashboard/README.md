# Admin Dashboard

## Description

A clean, professional admin dashboard layout designed for web applications. It includes a dark sidebar, top navigation, statistics cards, and a data table.

## Features

- Flexbox layout with a fixed sidebar and scrollable main content area
- 4 Key metric cards showing positive/negative trends
- Beautiful data table with avatar images and status badges
- Recent activity timeline widget
- Fully styled search bar and notification icons

## Technologies

- HTML5
- CSS3 (Flexbox, CSS Grid)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing complex, multi-panel layouts using a mix of Flexbox (for overall structure and nav) and CSS Grid (for dashboard widget layout).
- Using soft colored backgrounds for icons (`bg-blue`, `bg-green`) to indicate meaning and add visual flair without being overwhelming.
- Styling standard HTML tables to look like modern data grid components.
