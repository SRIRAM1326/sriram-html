# Registration Form

## Description

A modern, responsive registration form designed with a split-screen layout. It features a branded hero area on the left and a clean, comprehensive form on the right.

## Features

- Split-screen desktop layout (stacks on mobile)
- Client-side HTML5 validation (`required`, `type="email"`, `minlength`, `pattern`)
- Well-structured form rows for efficient space utilization
- Styled focus states for accessibility and user experience
- Custom checkbox alignment and styling

## Technologies

- HTML5
- CSS3 (Flexbox)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing form layouts using Flexbox to align inputs neatly in rows.
- Enhancing input focus states with `box-shadow` to create a glowing border effect.
- Using native HTML form validation attributes to ensure data integrity without JavaScript.
