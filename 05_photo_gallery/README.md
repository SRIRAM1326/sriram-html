# Photo Gallery

## Description

A visually stunning, responsive photo gallery utilizing CSS Grid. It features masonry-style sizing, smooth image zoom on hover, and an elegant caption overlay.

## Features

- CSS Grid layout automatically adjusting column counts based on screen width
- Varying row spans for a masonry-like aesthetic
- Smooth hover animations (image scale up, caption slide up)
- Category filter buttons (UI only, functional filtering requires JavaScript)
- Clean, minimal design letting the photos stand out

## Technologies

- HTML5
- CSS3 (CSS Grid, Transitions, Gradients)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Mastering CSS Grid `grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))` for fluid responsiveness without media queries.
- Using `grid-row: span 2` to create dynamic grid variations.
- Implementing absolute positioning within relative containers to create hover overlay effects.
