# Stock Market Dashboard

## Description

A sleek, frontend-only financial dashboard designed for displaying stock market data. Built with a dark theme optimal for financial tools, featuring a watchlist and detailed views. **All data displayed is demo data.**

## Features

- High-contrast dark theme using 'Space Grotesk' font for readability of financial figures
- CSS-only mini sparklines (bar charts) representing stock trends visually
- Prominent "Demo Data Only" warning banner
- Responsive flexbox/grid layout (summary cards stack on smaller screens)
- Trading activity feed UI

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing a financial UI where typography and color (Green for up, Red for down) dictate the user experience.
- Creating fake sparklines using Flexbox and inline heights for rapid prototyping without canvas/SVG or heavy JS libraries.
- Organizing complex numerical layouts using CSS Grid to maintain alignment.
