# Student Dashboard

## Description

A clean, modern dashboard UI designed for a student portal. Features a side navigation menu, quick stat overview cards, and detailed panels for assignments and course progress.

## Features

- Fixed sidebar navigation
- Dashboard statistic cards with colorful icons
- Progress bars using inline styles for dynamic widths
- Assignment list with warning states for upcoming deadlines
- Responsive design that hides the sidebar on mobile

## Technologies

- HTML5
- CSS3 (CSS Grid, Flexbox)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Building dashboard layouts utilizing `position: fixed` for the sidebar and pushing the main content over with `margin-left`.
- Designing clean UI cards with box-shadows to distinguish surface layers on a slightly off-white background (`#f4f7fe`).
- Creating CSS progress bars using nested divs and inline percentage widths.
