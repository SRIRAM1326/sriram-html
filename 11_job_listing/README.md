# Job Listing Page

## Description

A dynamic job board interface with functional client-side filtering. Users can search for jobs by title and filter by employment type and location.

## Features

- Flexbox layout with a responsive sidebar for filters
- Dynamic JavaScript filtering based on custom `data-` attributes
- Job cards displaying company logo, title, metadata (type, location, salary), and required skills
- Clear filters functionality

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Using `data-` attributes in HTML to store searchable metadata for DOM elements.
- Implementing multiple simultaneous filters in JavaScript (search text + select dropdown + checkboxes).
- Toggling a `.hidden` CSS class via JavaScript to dynamically show/hide elements.
