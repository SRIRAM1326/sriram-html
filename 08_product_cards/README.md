# Product Cards Showcase

## Description

A responsive product gallery displaying a grid of modern, stylish e-commerce product cards. 

## Features

- CSS Grid layout for responsive fluid columns
- Absolute positioning for badges (New, Discount) and wishlist buttons
- Beautiful hover effects on the entire card and the image specifically
- Flexbox structure inside cards to ensure buttons align perfectly at the bottom regardless of description length
- Pricing hierarchy (current price vs old price)

## Technologies

- HTML5
- CSS3 (Grid, Flexbox, Transitions)

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Managing complex card layouts where content height varies, using `flex: 1` on descriptions to push pricing rows to the very bottom.
- Using `mix-blend-mode: multiply` on images with white backgrounds to blend them seamlessly into the card's background.
