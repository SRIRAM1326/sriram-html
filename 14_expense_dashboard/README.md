# Expense Dashboard

## Description

A personal finance dashboard focusing on expense tracking. Features top summary metric cards, a recent transactions list, and a breakdown of expense categories using CSS-based horizontal bars.

## Features

- Gradient "Total Balance" hero card
- Transaction list with category-specific icon styling
- CSS-only data visualization for category spending
- Responsive grid layout

## Technologies

- HTML5
- CSS3

## How to Run

Open `index.html` in a web browser.

## What I Learned

- Designing financial interfaces that prioritize readability of numbers.
- Using CSS variables to easily map colors to specific expense categories (e.g., Food = Orange, Bills = Red).
- Creating simple horizontal bar charts using nested `div` elements and inline `width` styles, removing the need for heavy JavaScript charting libraries in simple use cases.
